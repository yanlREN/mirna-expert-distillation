## 2. Framework evolution

### Early foundation: conservation as evidence, not a permanent gate

The 2005 work made deep conservation useful for identifying ancient land-plant miRNA-target relationships (`src-doi-10-1105-tpc-105-032185`). The later 2018 framework explicitly prevents this history from becoming a circular rule: conservation is helpful but not definitive, because other small RNAs can be conserved and genuine young miRNAs need not be (`src-doi-10-1105-tpc-17-00851`). The stable reasoning action is therefore to distinguish **family history** from **locus identity** (`claim-axtell-c-001`, `claim-axtell-c-008`).

### Key turn: from candidate discovery to false-positive-controlled annotation

The 2008 standard and 2013 ShortStack method make a two-part turn visible: first define the evidence needed to distinguish plant miRNAs from siRNAs, then expose multiple locus features in a reproducible workflow (`src-doi-10-1105-tpc-108-064311`, `src-doi-10-1261-rna-035279-112`). The 2018 revision tightened this for big data by emphasizing replication and the asymmetric cost of false positives (`claim-axtell-c-002`, `claim-axtell-c-003`).

### External expansion: database curation and competing tools

Independent sources did not simply repeat the Axtell framework. They extended it into database-level quality layers (`src-pmid-30423142`, `src-doi-10.1093-nar-gkz894`), challenged universal tool ranking (`src-pmid-31253093`), and showed that divergent precursor populations require validated parameter adaptation (`src-pmid-26542525`). The result is a more robust current rule: use strict evidence categories, but test thresholds and software against the species and data type at hand.

### 2024–2026: annotation rigor applied to trans-species RNA

The public record shows a current branch into trans-species RNA mobility and selective Argonaute loading (`src-pmid-38288670`, `src-pmid-42417192`). This is not a license to infer cross-species transport from reads alone. The inherited annotation discipline instead suggests a staged chain: donor identity → source assignment → movement → recipient loading → direct target effect → phenotype. Only the published steps may be claimed.

## 5. Candidate transferable timeline heuristics

1. **Separate history from current criterion:** an early conservation-based discovery does not make conservation a required identity criterion.
2. **Treat tool creation as operationalization, not proof:** ShortStack/miRScore outputs expose checks; they do not replace locus review.
3. **Track database version and assembly:** a family name or database accession can persist while coordinates, arms or confidence change.
4. **Do not count collaboration-network concordance as independent replication:** shared authorship/criteria must be disclosed.
5. **Carry corrections forward:** corrected equations or metadata travel with any reuse, even when conclusions are unchanged.
6. **For current trans-species claims, stage the evidence chain:** identity and source precede transport; loading precedes target effect; target effect precedes phenotype causality.
