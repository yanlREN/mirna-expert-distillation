# Hailing Jin — 研究框架时间线（Research Agent A）

## 1. 说明

本时间线只依据截至 **2026-07-17** 已发表且身份核验通过的公开科学记录。它描述 Hailing Jin 参与的**团队研究轨迹**，不是人物传记，也不代表其当前个人意见。每一项事实均绑定 `HJ-A-Sxxx` 来源与 `HJ-A-Cxxx` claim；候选框架明确标记为 Agent 跨论文推断。

## 2. 阶段时间线

### 2006：病原诱导内源 siRNA 与植物免疫

HJ-A-S001 在 Arabidopsis–Pseudomonas avrRpt2 体系中研究 nat-siRNAATGB2，将病原诱导、小 RNA 生物发生、靶标表达和抗病表型连接起来（HJ-A-C001）。此时的核心问题是：植物内部产生的小 RNA 是否为免疫因果链的一部分，而不是单纯的感染伴随变化。

### 2007：扩展至细菌诱导长 siRNA 类别

HJ-A-S002 描述包括 AtlsiRNA-1 在内的细菌诱导长 siRNA，并通过小 RNA 克隆、blot 与突变体分析约束其生物发生（HJ-A-C002）。框架由“一个内源 siRNA”扩展为“感染条件下存在不同于经典 miRNA 的小 RNA 类型”，但仍限于指定植物–细菌体系。

### 2011：miRNA 网络与 AGO–靶标–分泌效应器链

HJ-A-S003 用 13 个文库比较三类 Pseudomonas 处理和两个早期时间点，报告响应性 miRNA 家族及方法间不完全一致（HJ-A-C003）。HJ-A-S004 更正 Figure 4b 的 U6 内参重复，建立了本项目必须采用的 correction-first 引用规则（HJ-A-C004）。

同年 HJ-A-S005 将 AGO2、miR393*、MEMB12 与 PR1 分泌/抗病表型相连（HJ-A-C005）。研究重心由“哪些小 RNA 改变”推进到“由哪个 AGO 装载、作用于哪个细胞过程、如何影响免疫输出”。

### 2013：病原小 RNA、宿主 AGO1 与跨界靶标

HJ-A-S006 报告选定 Botrytis sRNA 与植物 AGO1、宿主免疫基因抑制和毒力之间的联系（HJ-A-C006），把研究框架从植物内部小 RNA 转到 fungus→plant 的跨界效应。该论文在 2025 年出现 HJ-A-S007 erratum；当前合法元数据不显示具体更正项，因此图级/实验级复用保持 unresolved（HJ-A-C007），不能声称更正无关紧要。

### 2016：双向 RNAi 与外源 RNA 保护

HJ-A-S008 同时研究宿主产生 RNA 对真菌的作用以及真菌摄取外源 RNA，支持 HIGS 与 topical RNA 在 Botrytis/Verticillium 体系中的保护（HJ-A-C008）。这一步把跨界 RNAi 与可干预性连接，但“双向”只表示两个方向均有生物学证据，不证明载体、摄取和细胞内机制对称。

### 2018：植物 EV 作为 plant→fungus 小 RNA 递送证据

HJ-A-S009 用顺序纯化、核酸酶保护、TET8/TET9 遗传学、小 RNA/靶标与病害读出支持植物 EV-associated sRNA 递送到 Botrytis（HJ-A-C009）。相较 2016 年的“真菌能摄取 RNA”，这里进一步追问供体释放、载体状态和靶标功能。论文记录专利申请利益冲突，应透明保留但不能替代实验评价。

### 2021：EV 货物装载/稳定相关 RNA-binding proteins

HJ-A-S010 以 EV 蛋白组、密度梯度、TET8 免疫亲和、蛋白酶保护和突变体测试候选 RNA-binding proteins 对小 RNA association/loading/stability 的贡献（HJ-A-C010）。该论文有 HJ-A-S011 Publisher Correction；官方通知说明错误 Supplementary Information 文件已被正确文件替换（HJ-A-C011）。因此必须使用更正后补充材料，且仍不能把 association、loading 和 stabilization 压缩成一个无差别结论。

### 2022–2023：SIGS 配方工程与持续性

HJ-A-S012 报告 BioClay 在 tomato leaf/fruit 与 mature chickpea 的指定条件下延长 dsRNA 持久性和抗 Botrytis 保护（HJ-A-C012）。HJ-A-S013 进一步用人工脂质 nanovesicles 保护 dsRNA、促进真菌摄取，并在 tomato、grape、lettuce 与 rose 等测试对象中评估病害保护（HJ-A-C013）。

框架由“RNA 是否有效”变为“何种材料能保护 RNA、维持可用性、促进摄取并延长保护”。相关预印本不与 final paper 双计为独立证据。

### 2023：fungus→plant 的 EV 与 clathrin uptake route

HJ-A-S014 用真菌 EV、BcPLS1 标记、植物 clathrin 通路遗传学、clathrin-coated vesicle 分析以及 AGO1/靶标读出，支持 Botrytis sRNA 在 Arabidopsis 中主要经 clathrin-mediated endocytosis 进入的结论（HJ-A-C014）。这是对 2013 fungus→plant 效应链中“受体摄取”这一边的机制化，但不得外推为所有真菌 RNA 或所有植物的唯一通路。

### 2024：跨界货物由小 RNA 扩展至选定编码 mRNA

HJ-A-S015 使用 3WJ-Broccoli reporter、EV 分析、真菌 translating-ribosome affinity purification/多核糖体、异位表达和植物 knockout，支持选定 Arabidopsis mRNA 到达 Botrytis 翻译机器并影响感染（HJ-A-C015）。这一变化扩大了 cargo 范围，但没有证明所有植物 mRNA 都被选择性、囊泡内封装且功能性转移。

### 2026：供体由宿主扩展至工程化细菌

HJ-A-S016 的已发表摘要报告工程化 *Bacillus subtilis* 与 *Pseudomonas putida* 产生 dsRNA，细菌 EV RNA 进入 *Botrytis cinerea* 与 *Verticillium dahliae*，并在 Arabidopsis/tomato 保护实验中发挥作用（HJ-A-C016）。这把递送框架扩展为 living delivery platform。当前只使用摘要层信息，不补写不可访问的方法、剂量或图表细节。

## 3. 研究框架的历史变化

| 阶段 | 主要问题 | 增加的因果边 | 仍需防止的过度推断 |
|---|---|---|---|
| 2006–2007 | 感染诱导哪些植物内源小 RNA | 生物发生 → 靶标 → 抗病表型 | 发卡预测或表达变化不等于 miRNA/siRNA 身份与因果 |
| 2011 | 哪个 AGO/靶标/细胞过程产生免疫输出 | AGO loading → MEMB12 → PR1 secretion | 历史 miRNA* 记法不能随意映射至所有 arm/family |
| 2013–2016 | RNA 能否跨界作用并被病原摄取 | donor RNA → recipient AGO/target → virulence；外源 uptake | 靶标抑制或表型不自动证明完整运输链 |
| 2018–2021 | 载体与装载/稳定机制是什么 | release/carrier → protection → cargo association/loading | EV association 不等于所有 RNA 都在完整囊泡腔内 |
| 2022–2023 | 如何延长并扩大 topical RNA 保护 | formulation → stability/persistence → uptake → duration | 受控实验保护窗不等于田间普适持久性 |
| 2023–2024 | 反向摄取路线和非小 RNA cargo 如何验证 | CME uptake；mRNA → fungal ribosome/translation | 一个 pathosystem 的 uptake route 或选定 cargo 不可普适化 |
| 2026 | 能否由工程微生物持续生产/递送 RNA | bacterial production/EV → fungus → plant protection | 摘要证据不足以评价生态、田间与部署安全 |

## 4. 候选可迁移框架

### 4.1 Direction-resolved donor-to-phenotype chain（HJ-A-FW001；HJ-A-C017）

对新论文依次问：

1. donor 中的 RNA 身份和产生是否直接验证；
2. 是否有 release 证据；
3. cargo 是游离、蛋白复合物、EV-associated 还是囊泡腔内；
4. 胞外稳定性如何；
5. recipient uptake 是直接还是由 downstream readout 推断；
6. 是否进入正确细胞内 effector/翻译体系；
7. target action 是预测、相关、切割/抑制还是遗传因果；
8. phenotype 是否由 on-target 作用支持。

该框架在 fungal sRNA、plant EV sRNA、fungal EV sRNA、plant mRNA 与 bacterial dsRNA 等不同情境中复现，具备迁移性与区分度，但属于 Agent 推断。

### 4.2 Bidirectional-is-not-symmetric gate（HJ-A-FW002；HJ-A-C019）

对相反方向分别建表，不把 plant→fungus 的 EV 证据复制给 fungus→plant，也不把 plant CME 证据复制给 fungal uptake。这一门限可直接用于评审新的“bidirectional cross-kingdom RNA”主张。

### 4.3 RNA crop-protection translation ladder（HJ-A-FW003；HJ-A-C018）

按 target validity → RNA production → formulation stability → environmental persistence → pathogen uptake → on-target action → disease suppression → duration → host range → deployment constraints 分层。HIGS、裸 RNA、BioClay、人工囊泡和工程细菌处在不同 delivery modality，不能只用末端病害表型横向排名。

### 4.4 Correction-first evidence gate（HJ-A-FW004；HJ-A-C020）

先查更正再抽取图级证据；已知更正项必须替换，未知更正内容标记 unresolved 并转给 Citation Verifier。更正不自动等于论文无效，也不能自动假定“只是排版”。

## 6. 身份隔离与归属边界

- 核心论文的身份以 UCR/历史单位或通信邮箱、ORCID、植物–病原小 RNA 主题、重复合作者和权威元数据进行双锚核验。
- Vanderbilt oncology 同名作者未进入来源清单或任何 claim edge。
- “末位作者”“通信作者”“lead contact”“conception/supervision”只按可访问作者/贡献记录书写；未明示通信关系的论文不推断通信作者。
- 论文所述均为团队研究结果。候选框架只可写为“基于公开团队研究轨迹的推断”，不得写成“Jin 会认为”或第一人称冒充。

## 7. 证据缺口

1. HJ-A-S007 的 2025 Science erratum 正文在当前合法访问路径中不可见，细粒度复用继续受限；HJ-A-S011 已由 Citation Verifier 解析为替换错误的 Supplementary Information 文件，必须使用更正后文件。
2. HJ-A-S016 仅有摘要层访问，方法和 figure 细节不得引用。
3. 本 Agent 的时间线旨在提炼研究轨迹，独立实验室支持和领域共识需由其他研究维度与 Scientific Reviewer 汇合。
4. 尚未评估田间多季效果、非靶生物、环境残留、法规或规模化生产；不得从现有 controlled assays 推断已完成部署验证。
